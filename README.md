# CTN MVP (Carbon Token Network)

CTN MVP is a platform for tracking solar energy generation, minting carbon credits on the blockchain, and tracking them to offset carbon emissions.

## 🚀 End-to-End Functions

The platform provides a complete lifecycle for carbon credits:

1. **Data Ingestion**: Solar energy generation readings (kWh) are ingested and stored, mapping device generation to CO2 avoided (using the CEA Grid Emission Factor).
2. **Aggregated Credit Creation**: The system aggregates raw energy readings until 1,000 kg (1 tonne) of CO2 is avoided, automatically minting a discrete 1-tonne Carbon Credit in the database and backing it to IPFS.
3. **On-Chain NFT Minting**: Admins can securely mint these verified credits as NFTs on the Polygon (Amoy) blockchain. The smart contract acts as the ultimate ledger of truth.
4. **Marketplace & Trading**: Users can explore available credits, view detailed stats, and purchase them (simulated payment flow).
5. **Credit Retirement**: To offset a carbon footprint, credits can be permanently "retired" on the blockchain, preventing double counting.

## 🧪 Manual Tests for Reviewers

Reviewers can try the following end-to-end flows to explore the MVP:

### Test 1: Explore as an Installer (User Flow)
1. Navigate to the **Login Page** (`/login`).
2. Log in using the **Demo Installer Account** credentials.
3. Once logged in, explore the **Installer Dashboard** (`/app`). Notice the live stats regarding energy generated (kWh), CO2 avoided, and credits earned.
4. Navigate to the **History Page** (`/app/history`) to see the detailed log of raw generation readings that contribute towards credits.

### Test 2: Admin Minting & Blockchain Verification
1. Log out (or open a new Incognito window) and navigate to the **Login Page**.
2. Log in using the **Admin Account** credentials.
3. Go to the **Admin Dashboard** (`/admin`). Here you will see the list of unminted credits generated by installers.
4. Select a credit and click **Mint to Blockchain**. Wait for the transaction to process.
5. Once minted, click the verification link (Polygonscan) to view the actual transaction on the Polygon Amoy testnet.
6. Check the IPFS link provided to view the immutable JSON metadata of the credit.

### Test 3: The Marketplace & Retiring Credits
1. Go to the **Marketplace** (`/marketplace`).
2. Browse the listed carbon credits and view their stats and real-world equivalents (e.g., equivalent to planting trees or taking cars off the road).
3. Try initiating a purchase. (Note: Payment processing is simulated for the MVP).
4. **Admin only**: From the Admin dashboard, select a previously minted credit and choose the **Retire** action. This updates the blockchain state to mark the credit as used (retired), completing the carbon offset lifecycle.
